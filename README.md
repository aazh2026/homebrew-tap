# specgate Homebrew Tap

```bash
brew tap aazh2026/specgate
brew install specgate
```

Or run it without installing:

```bash
brew install aazh2026/specgate/specgate
specgate --help
```

[specgate](https://github.com/aazh2026/specgate) measures requirement coverage —
like test coverage, but for acceptance criteria. Deterministic, no LLM at runtime.

Current formula version: **0.1.4** (tracks the upstream `v0.1.4` release tag).
